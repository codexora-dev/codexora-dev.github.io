한국어로 시작하는 프로그래밍

코드를 읽고, 배우고, 작성하는 가장 자연스러운 시작.

Hangullo은 한국어 기반 문법과 초보자 친화적인 흐름을 중심으로 만들어진 프로그래밍 언어 프로젝트입니다. 변수, 조건문, 반복문, 함수처럼 기본 개념을 더 직관적으로 이해할 수 있도록 설계됩니다.

언어 소개

Hangullo은 프로그래밍을 어렵게 만들기보다 자연스럽게 시작하게 하는 데 초점을 둡니다.

  • 한국어 문법으로 코드를 읽기 쉬움
  • 초보자 학습에 적합한 반복 학습 구조
  • 예제와 IDE를 연결하는 개발 경험
  • 오픈소스 프로젝트로 계속 확장 중

시작하기

3단계로 Hangullo을 시작할 수 있습니다.

1

저장소 확인

GitHub 저장소에서 Hangullo 프로젝트를 받아 실행 환경을 준비합니다.

2

IDE 실행

Python 기반 IDE를 실행해 .han 파일을 작성하고 바로 테스트합니다.

3

코드 실행

출력, 입력, 조건문, 반복문을 실습하며 기본 흐름을 익힙니다.

설치

Windows에서 소스로 시작하는 설치 방식

Windows

프로젝트를 다운로드한 뒤, IDE를 실행하면 Hangullo 코드를 작성할 수 있습니다.

cd C:\Users\사용자명\Desktop\Hangullo
python IDE\app.py

또는 IDE 폴더의 run.bat 를 실행할 수 있습니다.

현재 지원 범위

공식 독립 실행 파일과 macOS용 패키지는 아직 제공되지 않습니다.

지원 환경과 실행 방법은 저장소 및 시작 문서에서 확인할 수 있습니다.
