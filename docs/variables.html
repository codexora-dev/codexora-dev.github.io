변수

변수로 이름을 선언하고 =로 값을 저장하거나 갱신합니다.

선언과 대입

새 변수에는 변수를 붙입니다. 선언한 변수는 이후 대입문으로 값을 바꿀 수 있습니다.

변수 이름 = "Hangullo"
변수 점수 = 80
점수 = 점수 + 10
출력(이름)
출력(점수)

이름 규칙

이름은 한글·영문 문자 또는 밑줄로 시작할 수 있고, 뒤에는 숫자도 사용할 수 있습니다. 공백은 허용되지 않으며 예약어는 이름으로 쓸 수 없습니다.

변수 사용자이름 = "민서"
변수 user_name2 = "Hangullo"

현재는 정적 타입 선언이나 상수 선언 문법이 없습니다. 지원되는 값은 자료형 안내를 참고하세요.
