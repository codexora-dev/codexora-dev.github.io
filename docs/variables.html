변수

변수에 값을 저장하고 프로그램의 여러 위치에서 다시 사용하는 방법입니다.

변수 선언

변수 뒤에 이름과 =를 작성합니다.

변수 이름 = "Hangullo"
변수 나이 = 10
출력 이름
출력 나이

값 다시 대입하기

변수 점수 = 80
점수 = 점수 + 10
출력 점수

변수 이름

한글과 영문 이름을 사용할 수 있습니다. 공백이 들어간 이름이나 숫자로 시작하는 이름은 피하세요.

주의

아직 상수 선언이나 복잡한 자료구조는 지원하지 않습니다. 현재는 숫자, 문자열, 논리값 중심으로 사용합니다.
