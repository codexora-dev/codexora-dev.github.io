Han IDE 사용법

프로젝트 파일을 열고 Han 코드를 작성한 뒤 IDE 안에서 실행하는 흐름을 설명합니다.

기본 작업 흐름

  1. 파일 탐색기에서 프로젝트 폴더를 엽니다.
  2. .han 파일을 탭으로 열거나 새 파일을 만듭니다.
  3. 편집기에서 코드를 작성합니다.
  4. 실행 버튼 또는 F5를 눌러 콘솔 결과를 확인합니다.

주요 단축키

F5 현재 파일 실행

F6 컴파일 동작

Ctrl + S 파일 저장

설정

IDE 설정에서 테마, 글꼴, 글자 크기, 줄 번호, 자동 줄바꿈을 조정할 수 있습니다. 실행 중 입력은 하단 콘솔에서 처리합니다.
