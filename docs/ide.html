Hangullo IDE

파일을 편집하고 컴파일하거나 실행하는 Hangullo 데스크톱 편집기입니다.

기본 작업 흐름

  1. 파일 탐색기에서 프로젝트 폴더를 엽니다.
  2. .hg 파일을 열거나 새 파일을 만듭니다.
  3. 코드를 작성하고 저장합니다.
  4. F5로 실행하거나 F6으로 컴파일한 뒤 콘솔을 확인합니다.

단축키

Ctrl + N 새 파일

Ctrl + O 파일 열기

Ctrl + S 저장

Ctrl + Shift + S 다른 이름으로 저장

Ctrl + F 찾기

F6 컴파일

F5 저장 후 실행

설정과 입력

설정에서 테마, 글꼴, 글자 크기, 줄 번호, 자동 줄바꿈과 프로젝트 경로를 조정할 수 있습니다. 프로그램이 입력을 요청하면 IDE 콘솔에서 값을 입력합니다.

IDE를 설치하려면 다운로드 안내를 확인하세요.
