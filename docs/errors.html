오류 해결

오류 메시지에서 파일 위치와 원인을 확인하고 작은 단위로 코드를 점검하세요.

자주 확인할 항목

문법 오류

조건문, 반복문, 함수의 시작과 끝이 맞는지 확인합니다. 키워드 뒤의 공백과 들여쓰기도 함께 점검하세요.

이름 오류

선언하지 않은 변수나 함수를 사용하면 오류가 발생할 수 있습니다. 이름의 철자와 선언 순서를 확인합니다.

실행 오류

0으로 나누기, 잘못된 값의 연산처럼 실행 중 발생한 오류는 콘솔의 마지막 메시지부터 확인합니다.

문제 재현하기

  1. 오류가 나는 코드를 가장 작은 예제로 줄입니다.
  2. 오류 메시지의 파일과 줄 위치를 확인합니다.
  3. 한 번에 한 부분만 수정하고 다시 실행합니다.

참고

Hangullo IDE는 Hangullo 코드 오류를 정리해 보여주지만 모든 Python 실행 오류를 동일한 형식으로 변환하지는 않습니다. 원본 콘솔 메시지도 함께 확인하세요.
