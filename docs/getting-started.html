첫 번째 Han 프로그램 실행하기

현재 공개 저장소는 Windows와 Python 환경에서 소스로 실행하는 방식이 가장 정확합니다.

1. 저장소 준비

Han GitHub 저장소를 내려받고 압축을 풀거나 Git으로 복제합니다.

2. IDE 실행

cd C:\Users\사용자명\Desktop\Han
python IDE\app.py

또는 Windows 탐색기에서 IDE\run.bat을 실행할 수 있습니다. Python 3가 설치되어 있어야 합니다.

3. 첫 파일 작성

IDE에서 새 파일을 만들고 hello.han으로 저장한 뒤 아래 코드를 입력합니다.

출력 "안녕하세요, Han!"

변수 이름 = "Han"
출력 "반갑습니다, " + 이름

4. 실행

F5 또는 실행 버튼을 누르면 결과가 하단 콘솔에 표시됩니다. 입력이 필요한 프로그램은 콘솔에 값을 입력하세요.

현재 환경 안내

공식 독립 실행 파일과 macOS용 실행 패키지는 아직 제공되지 않습니다. 지원 범위가 바뀌면 GitHub 저장소와 이 문서에 반영합니다.
