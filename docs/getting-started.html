Hangullo 설치 및 첫 프로그램 실행

설치 파일 다운로드부터 IDE에서 첫 프로그램을 실행하기까지의 절차를 설명합니다.

1. 다운로드 메뉴 열기

사이트 상단의 다운로드 메뉴를 선택합니다.

2. 설치 파일 다운로드

다운로드 페이지에서 Hangullo 다운로드 버튼을 누릅니다. 설치 파일은 Google Drive에서 제공됩니다.

Windows 설치 파일 다운로드 · 11 MB

3. 설치 파일 실행

다운로드한 파일을 열고 화면의 안내에 따라 설치를 완료합니다.

4. 첫 프로그램 실행

Hangullo IDE에서 새 파일을 hello.hg로 저장한 뒤 아래 코드를 입력합니다.

출력("안녕하세요, Hangullo!")

F5 또는 실행 버튼을 누르면 결과가 IDE 콘솔에 표시됩니다. 문법은 Hangullo 문법 안내를 참고하세요.
