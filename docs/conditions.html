조건문

만약과 아니면으로 조건에 따른 실행 흐름을 작성합니다.

기본 조건

변수 점수 = 80
만약 점수 >= 60
    출력 "합격"
끝

조건이 거짓일 때

변수 나이 = 15
만약 나이 >= 18
    출력 "성인"
아니면
    출력 "미성년자"
끝

조건 블록은 끝으로 닫습니다. 비교 연산 결과는 참 또는 거짓으로 판단됩니다.

현재 지원 범위

기본적인 만약과 아니면을 지원합니다. 다중 조건인 아니면만약은 현재 안정적인 사용 대상으로 안내하지 않습니다.
