자료형

현재 Hangullo 실행기에서 사용할 수 있는 값의 종류와 아직 개발 중인 기능을 구분해 설명합니다.

현재 사용할 수 있는 값

정수와 실수

소수점이 없는 정수와 소수점을 포함한 실수를 사용할 수 있습니다.

변수 횟수 = 3
변수 비율 = 1.5

문자열

큰따옴표로 문자열을 표현하고 +로 이어 붙일 수 있습니다.

변수 이름 = "Hangullo"
출력 "안녕, " + 이름

논리값

조건식은 참 또는 거짓으로 평가되어 조건문에 사용됩니다.

개발 중인 자료형

목록, 사전, 집합, 사용자 정의 자료형은 설계 문서에 방향이 기록되어 있지만 현재 실행기에서 지원되는 기능으로 안내하지 않습니다.
