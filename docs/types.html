값과 자료형

현재 문법에서 사용할 수 있는 리터럴과 입력값의 기본 특성을 설명합니다.

숫자

정수와 소수점이 있는 실수를 작성할 수 있습니다.

변수 횟수 = 3
변수 비율 = 1.5
출력(횟수 + 비율)

문자열

문자열은 큰따옴표로 감쌉니다. \n, \t, \", \\ 이스케이프를 지원합니다. 문자열은 +로 연결할 수 있습니다.

변수 인사 = "안녕하세요, "
변수 이름 = "Hangullo"
출력(인사 + 이름)

논리값과 범위

논리 리터럴은 참과 거짓입니다. 현재 문법은 리스트·사전 리터럴이나 사용자 정의 자료형을 제공하지 않습니다. 입력으로 받은 값은 문자열입니다.

변수 실행_가능 = 참
만약 실행_가능:
    출력("시작")
