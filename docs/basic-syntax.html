Hangullo 언어 문법

이 문서는 현재 공개된 Hangullo 컴파일러가 처리하는 소스 형식과 문법을 정의합니다. 별도로 명시하지 않은 기능은 지원된다고 가정하지 않습니다.

1. 소스 파일과 문장

소스 파일은 UTF-8로 인코딩하고 .hg 확장자를 사용합니다. 각 문장은 줄바꿈으로 구분합니다. 문장 끝에 세미콜론을 쓰지 않습니다.

# hello.hg
출력("안녕하세요, Hangullo!")

2. 주석과 들여쓰기

# 또는 //부터 줄 끝까지는 주석으로 처리합니다. 블록은 콜론(:)으로 시작하고 들여쓰기로 범위를 나타냅니다. 공백 4칸을 권장하며, 같은 블록 안에서는 들여쓰기 깊이를 일관되게 유지합니다. 블록을 닫는 끝 키워드는 없습니다.

# 한 줄 주석
// 이것도 한 줄 주석
만약 참:
    출력("들여쓴 문장은 조건 블록에 속합니다.")

3. 식별자와 값

식별자는 한글 또는 영문 문자나 밑줄(_)로 시작하고, 뒤에 문자·숫자·밑줄을 이어 쓸 수 있습니다. 예약어는 이름으로 사용할 수 없습니다.

리터럴은 정수, 소수, 큰따옴표 문자열, 논리값 참과 거짓을 지원합니다. 문자열은 한 줄 안에서 닫아야 하며 \n, \t, \", \\ 이스케이프를 사용할 수 있습니다.

변수 이름 = "Hangullo"
변수 횟수 = 3
변수 비율 = 1.5
변수 사용_가능 = 참

4. 변수와 대입

변수로 변수를 선언합니다. 선언한 이름에는 =로 새 값을 대입할 수 있습니다.

변수 점수 = 90
점수 = 점수 + 5

5. 연산자와 식

산술 연산자는 +, -, *, /, %입니다. 비교 연산자는 ==, !=, <, <=, >, >=입니다. 논리 연산자는 그리고, 또는, 단항 연산자 아니다입니다. 괄호로 식의 계산 순서를 명시할 수 있습니다.

연산자 우선순위는 높은 순서부터 괄호, 단항 연산, 곱셈·나눗셈·나머지, 덧셈·뺄셈, 비교, 같음 비교, 그리고, 또는입니다.

변수 결과 = (2 + 3) * 4
만약 점수 >= 60 그리고 아니다 결석:
    출력("통과")

6. 출력과 입력

출력(식)은 식의 값을 표시합니다. 입력(변수)는 입력을 지정한 변수에 저장하고, 선택적 두 번째 인수로 안내 문구를 표시합니다. 입력도 식 안에서 사용할 수 있습니다.

출력("이름을 입력하세요.")
입력(이름, "이름: ")
출력("반갑습니다, " + 이름)
변수 이름 = 입력(이름, "이름: ")

7. 조건문

만약으로 조건을 시작합니다. 추가 조건에는 아니고만약, 나머지 경우에는 아니면을 사용합니다. 각 분기 뒤에는 콜론과 들여쓴 블록이 필요합니다.

만약 점수 >= 90:
    출력("A")
아니고만약 점수 >= 80:
    출력("B")
아니면:
    출력("C")

8. 반복문

반복 식:은 식의 값을 정수로 변환한 횟수만큼 블록을 실행합니다. 0 이하의 횟수이면 블록을 실행하지 않습니다.

반복 3:
    출력("반복")

9. 함수와 반환

함수 이름(매개변수):로 함수를 정의합니다. 매개변수는 쉼표로 구분하며, 함수 본문은 들여써야 합니다. 반환 식은 함수에서 값을 돌려줍니다.

함수 더하기(가, 나):
    반환 가 + 나

변수 합계 = 더하기(3, 5)
출력(합계)

10. 실행

Hangullo IDE에서 .hg 파일을 열고 F5 또는 실행 버튼을 누르면 프로그램이 실행됩니다. 컴파일만 하려면 F6을 누릅니다.

11. 지원 범위

이 버전은 변수, 입출력, 식, 조건문, 횟수 반복문, 함수와 반환을 지원합니다. 클래스, 모듈, 컬렉션 반복, 예외 처리, 사용자 정의 자료형, 자체 가상 머신과 바이트코드는 지원하지 않습니다.

설치와 실행 절차는 Hangullo 설치 및 시작하기를 참고하세요. 이 문서는 v0.0.1-beta 구현 기준이며, 이후 버전의 변경 사항은 저장소의 문법 문서와 릴리스를 확인하세요.
