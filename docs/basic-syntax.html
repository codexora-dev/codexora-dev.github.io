기본 문법

Hangullo 소스 파일의 형식과 코드 작성에 필요한 기본 규칙입니다.

파일 형식

Hangullo 소스 파일은 UTF-8로 저장하며 확장자는 .hg을 사용합니다. 한 줄에 하나의 명령문을 작성하는 방식을 권장합니다.

주석

설명만 남기고 실행하지 않을 코드는 # 또는 //로 시작합니다.

# 한 줄 주석
// 이것도 주석입니다
출력 "실행되는 코드"

이름 작성

변수와 함수 이름에는 한글 또는 영문을 사용할 수 있습니다. 예약어와 숫자로 시작하는 이름은 식별자로 사용할 수 없습니다.

변수 사용자이름 = "Hangullo"
변수 user_name = "Hangullo"

현재 구현 범위

문법은 개발 중이며 버전에 따라 변경될 수 있습니다. 클래스, 모듈, 사용자 정의 자료형은 현재 실행 기능에 포함되지 않습니다.
