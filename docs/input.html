입력

입력으로 실행 중 사용자에게서 한 줄을 받아 변수에 저장합니다.

프롬프트와 입력

첫 번째 인수는 입력값을 저장할 변수 이름입니다. 두 번째 인수는 선택 사항이며, 입력 전에 표시할 문자열입니다. 입력 결과는 문자열입니다.

입력(이름, "이름을 입력하세요: ")
출력("안녕하세요, " + 이름)

입력을 식으로 사용하기

입력 호출의 결과를 변수 선언이나 다른 식에 사용할 수도 있습니다.

변수 응답 = 입력(응답, "계속하려면 입력하세요: ")
출력("입력한 값: " + 응답)

IDE에서는 콘솔에 값을 입력합니다. CLI로 실행하는 경우 프로그램을 실행한 터미널에서 입력하세요. 숫자로 계산하려면 입력값을 숫자로 변환해야 합니다.
