오류 해결

초보자도 이해할 수 있는 오류 안내를 목표로 합니다.

Hangullo은 내부적으로 Python 예외를 사용할 수 있지만, 사용자에게는 가능한 경우 이해하기 쉬운 한국어 메시지로 안내합니다.

오류를 확인하는 방법

IDE의 콘솔에서 오류 코드, 위치, 설명을 확인합니다. 줄 번호와 코드 위치를 함께 살펴보면 원인을 빠르게 찾을 수 있습니다.

오류 복사

문제 발생 시 콘솔 위의 오류 복사 버튼을 사용해 메시지를 복사하고 GitHub 이슈에 공유할 수 있습니다.

자주 발생하는 오류

정의되지 않은 이름, 자료형 문제, 값 범위 문제, 0으로 나누기, 파일 경로 오류 등이 대표적입니다.

원인별 해결 팁

  • 정의되지 않은 이름: 변수나 함수 이름을 다시 확인합니다.
  • 자료형 문제: 연산이나 함수에 전달하는 값의 형태를 점검합니다.
  • 값이 올바르지 않음: 입력 값이나 비교 대상 범위를 확인합니다.
  • 0으로 나눔: 나누는 값이 0인지 확인합니다.
  • 파일 문제: 파일 경로와 이름을 다시 확인합니다.

오류 메시지 정리 원칙

Hangullo의 현재 설계 문서는 오류 메시지를 단순한 기술 문구가 아니라 학습과 개선을 돕는 도구로 보도록 정리되어 있습니다. 이 원칙에 따라 사용자에게는 설명이 쉬운 한국어 안내를 우선합니다.
