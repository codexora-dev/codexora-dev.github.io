오류 해결

오류를 좁히고 원인을 확인하세요.

Hangullo는 컴파일 단계의 오류와 일부 실행 오류를 별도로 표시합니다. 메시지와 문제가 발생한 줄을 함께 확인하세요.

오류를 확인하는 방법

IDE 콘솔 또는 CLI 출력을 확인합니다. 파일 경로, 오류 종류, 줄 번호가 표시되면 해당 소스 줄부터 점검합니다.

오류 복사

오류 메시지와 최소 재현용 .hg 코드를 함께 정리해 GitHub 이슈에 공유합니다.

자주 발생하는 오류

콜론 누락, 잘못된 들여쓰기, 괄호 누락, 선언되지 않은 이름, 0으로 나누기 등이 자주 확인할 항목입니다.

원인별 해결 팁

  • 출력 또는 입력 구문 오류: 호출 괄호와 쉼표 위치를 확인합니다.
  • 블록 오류: : 뒤에 코드가 들여쓰기 되었는지, 같은 블록의 들여쓰기 깊이가 같은지 확인합니다.
  • 알 수 없는 이름: 변수·함수의 철자와 선언 순서를 확인합니다.
  • 실행 오류: 나눗셈의 0 여부와 연산에 전달한 값의 유형을 확인합니다.
  • 파일을 찾지 못함: 프로젝트 루트에서 명령을 실행했는지 확인합니다.

오류 메시지 정리 원칙

컴파일 오류는 가능한 경우 Hangullo 문법 설명과 소스 위치를 제공합니다. 실행 오류가 모두 같은 형식으로 변환되는 것은 아니므로 원본 메시지도 함께 확인하세요.
