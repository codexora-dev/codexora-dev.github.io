Han IDE

코드 작성, 실행, 오류 확인까지 한 번에.

Han IDE는 실제 저장소에 포함된 기능을 기준으로 텍스트 기반 코딩 환경을 중심으로 제공합니다.

텍스트 코딩 모드

.han 파일을 직접 편집하고 코드 구조를 메인 작업 환경에서 작성할 수 있습니다.

실행

코드를 실행하고 결과를 콘솔에서 확인하는 흐름을 지원합니다.

중지

실행 중인 프로그램을 중단해야 할 때 사용할 수 있는 중지 기능이 포함되어 있습니다.

콘솔

실행 결과와 입력값, 오류 상태를 한 화면에서 확인할 수 있습니다.

오류 메시지

오류 코드와 위치 정보를 함께 보여주며, 복잡한 원시 에러를 더 읽기 쉽게 설명하는 방향으로 구성됩니다.

오류 복사

오류 메시지를 그대로 복사하여 저장소 이슈나 질문에 공유할 수 있게 설계되어 있습니다.

IDE의 실제 강점

  • 파일 탐색기와 탭 기반 편집
  • 문법 강조 기능
  • 실행 / 중지 / 콘솔 관리
  • 테마, 폰트, 줄 번호 설정
  • 입력 테스트 기능
