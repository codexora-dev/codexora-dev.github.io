Hangullo IDE

코드를 편집하고 실행하는 데스크톱 환경.

Hangullo IDE는 파일 편집, 컴파일과 실행 기능을 제공하는 데스크톱 편집기입니다.

텍스트 코딩 모드

.hg 파일을 탭에서 편집하고 저장할 수 있습니다.

실행

현재 파일을 컴파일하거나 실행하고 출력 결과를 콘솔에서 확인합니다.

중지

실행 메뉴에서 실행 중인 프로그램을 중단할 수 있습니다.

콘솔

실행 출력과 프로그램 입력을 콘솔에서 처리합니다.

오류 메시지

컴파일러 오류와 실행 중 오류를 콘솔에서 확인합니다. 일부 실행 오류에는 한국어 안내가 표시됩니다.

오류 복사

오류가 발생하면 콘솔의 메시지를 확인하고, 재현 코드와 함께 저장소 이슈에 공유할 수 있습니다.

IDE의 실제 강점

  • 파일 열기, 새 파일, 탭 편집 및 저장
  • 예약어·문자열·숫자·주석 구문 강조
  • 컴파일(F6), 저장 후 실행(F5), 실행 중지
  • 테마, 글꼴, 글자 크기, 줄 번호, 자동 줄바꿈 설정
  • 프로그램 입력을 IDE 콘솔에서 전달
