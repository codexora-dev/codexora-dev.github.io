Han 소개

한국어로 프로그래밍을 익히는 새로운 방향

Han은 영어 중심 문법에 익숙하지 않은 사용자도 더 자연스럽게 프로그래밍 개념을 배우고 이해할 수 있도록 설계된 한국어 기반 프로그래밍 언어 프로젝트입니다.

Han을 만들게 된 이유

많은 프로그래밍 언어는 영어 키워드와 영어 중심 개발 환경을 기반으로 만들어졌습니다. 코드가 읽히는 방식과 사고의 흐름 사이에 언어 장벽이 생기면 초보자는 개념을 배우는 과정에서 어려움을 느낄 수 있습니다.

Han 프로젝트는 이런 점을 개선하고자 한국어 문법을 중심에 두고, 교육용으로도 실무적으로도 쉽게 접근할 수 있는 구조를 설계합니다.

핵심 방향

  • 한국어 기반 문법
  • 초보자 친화적인 학습 경험
  • 읽기 쉬운 코드 구조
  • 오픈소스 개발 생태계
특징

Han의 목표는 단순한 번역이 아니라 이해의 편의성입니다.

한국어 중심

변수, 조건문, 반복문, 함수 같은 핵심 문법을 한국어로 표현하여 학습 부담을 줄입니다.

교육 친화적

처음 프로그래밍을 접하는 사용자가 코드의 의미를 직관적으로 이해할 수 있도록 설계합니다.

개발 초기 단계

현재 Han은 문법 설계, IDE 구현, 컴파일러 구조와 개발 도구에 집중하는 초기 단계 프로젝트입니다.

현재 개발 상태

Han 프로젝트는 현재 초기 개발 단계입니다. 저장소에는 문법 설계 문서, 예제 코드, IDE, 컴파일러 구조, 오류 처리 로직이 포함되어 있으며, 앞으로 문법과 도구를 더 정교하게 확장할 예정입니다.
