Hangullo 소개

한국어를 코드의 언어로.

Hangullo는 한국어 키워드와 한글 식별자를 사용하는 오픈소스 프로그래밍 언어입니다. 현재 v0.0.1-beta에서 핵심 문법을 실행하는 컴파일러와 데스크톱 IDE를 개발하고 있습니다. Hangullo는 Python으로 제작되었습니다.

한국어로 생각한 흐름을 코드로 옮깁니다.

많은 프로그래밍 언어는 영어 키워드와 영어 중심 개발 환경을 기반으로 만들어졌습니다. 코드가 읽히는 방식과 사고의 흐름 사이에 언어 장벽이 생기면 초보자는 개념을 배우는 과정에서 어려움을 느낄 수 있습니다.

Hangullo는 한국어를 사용하는 사람이 프로그래밍 개념을 익힐 때 키워드의 언어 장벽을 낮추고, 코드의 실행 흐름에 집중할 수 있도록 한국어 문법을 실험합니다. 아직 초기 베타이며, 범용 개발 도구로 검증된 제품이라고 주장하지 않습니다.

핵심 방향

  • 한국어 기반 문법
  • 한글과 영문 식별자
  • 명시적인 콜론과 들여쓰기 블록
  • 공개 저장소와 테스트 중심 개발
특징

작은 문법을 명확하게 구현하는 것부터 시작합니다.

한국어 중심

변수, 조건문, 반복문, 함수 같은 핵심 문법을 한국어로 표현하여 학습 부담을 줄입니다.

교육 친화적

읽기 쉬운 한국어 키워드와 예제를 통해 핵심 제어 흐름을 익힐 수 있도록 설계합니다.

개발 초기 단계

현재 버전은 lexer, parser와 코드 생성기를 갖춘 초기 베타이며 기능과 명세가 발전 중입니다.

현재 개발 상태

Hangullo v0.0.1-beta는 변수, 입출력, 조건문, 횟수 반복문, 함수와 반환을 지원합니다. 클래스, 모듈, 컬렉션 반복, 예외 처리, 패키지 관리자는 현재 지원 범위에 포함되지 않습니다.

현재 포함 핵심 문법, 명령줄 도구, 데스크톱 IDE, 실행 예제
설계 문서 현재 구현을 기준으로 한 문법 안내
향후 방향 공개 저장소에서 진행 상황 확인
