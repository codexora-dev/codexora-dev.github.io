# Hangullo 공식 웹사이트

이 폴더는 Hangullo 프로그래밍 언어의 공식 정적 웹사이트 소스입니다.

## 구조

- `index.html`: 메인 홈 페이지
- `about.html`: Hangullo 소개 페이지
- `getting-started.html`: 시작하기
- `docs.html`: 문서 페이지
- `ide.html`: IDE 소개
- `troubleshooting.html`: 오류 해결
- `download.html`: 다운로드
- `css/style.css`: 공통 스타일시트
- `js/main.js`: 공통 스크립트

## 참고

- 공식 GitHub: https://github.com/codexora-dev/Hangullo
- 현재 저장소의 실제 구현 범위와 문서를 기준으로 작성했습니다.
- 실제 배포 파일이 없는 경우 "준비 중"으로 안내하고 있습니다.
