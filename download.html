설치 및 다운로드

Han을 내려받고 개발 환경을 준비하세요.

현재 공식 독립 실행 파일은 배포되지 않았습니다. GitHub 저장소를 내려받아 Python 기반 IDE를 실행하는 방법이 가장 정확합니다.

Windows

GitHub 저장소를 ZIP으로 내려받은 뒤 원하는 위치에 압축을 풉니다.

Python 3가 설치되어 있는지 확인하고 프로젝트의 IDE\app.py를 실행합니다.

cd C:\Users\사용자명\Desktop\Han
python IDE\app.py

IDE 폴더의 run.bat을 더블클릭해 실행할 수도 있습니다.

macOS

macOS는 현재 지원을 하지 않습니다.

빠른 시일 내에 지원을 할 수 있도록 노력하겠습니다.
