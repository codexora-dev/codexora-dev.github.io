설치 및 다운로드

Han을 설치하고 바로 시작하세요.

현재 저장소에는 공식 릴리스 파일이 공개되어 있지 않으므로, 가장 현실적인 설치 방법은 GitHub 저장소에서 소스를 내려받고 IDE를 실행하는 것입니다.

Windows

ZIP파일을 다운로드한 뒤 원하는 위치에 압축을 풉니다.

파일들 중 Han.exe파일을 원하는 위치로 이동합니다.

Han.exe파일을 실행한 후 설정에서 프로젝트 경로를 설정합니다.
만약 프로젝트 경로를 설정하기 어렵다면 자동찾기 기능을 이용하세요.

기존 저장소 구조를 그대로 사용하고, IDE 화면에서 .han 파일을 작성해 실행할 수 있습니다.

Han 다운로드

macOS

macOS는 현재 지원을 하지 않습니다.

빠른 시일 내에 지원을 할 수 있도록 노력하겠습니다.

감사합니다.
