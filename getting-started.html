시작하기

처음 Hangullo을 접하는 사람도 바로 시작할 수 있습니다.

Hangullo IDE는 Python 기반으로 동작하며, 저장소를 내려받아 폴더 안에서 실행할 수 있습니다.

1

Hangullo 저장소를 내려받습니다.

GitHub 저장소에서 현재 코드를 다운로드하거나 로컬에 복제합니다.

GitHub 저장소 열기
2

IDE를 실행합니다.

프로젝트 루트에서 IDE 폴더 안의 app.py를 실행하거나 run.bat를 사용합니다.

3

첫 번째 파일을 만듭니다.

새 파일을 만들고 .han 확장자로 저장한 뒤 예제를 입력해 보세요.

4

실행합니다.

IDE의 실행 버튼 또는 F5 키를 눌러 결과를 확인하고, 콘솔을 살펴보세요.

Windows

  1. Hangullo 저장소를 로컬에 다운로드합니다.
  2. 프로젝트 폴더 안에서 Hangullo/IDE 경로로 이동합니다.
  3. 아래와 같이 실행합니다.
cd C:\Users\사용자명\Desktop\Hangullo
python IDE\app.py

또는 IDE 폴더의 run.bat 파일을 실행해 같은 작업을 진행할 수 있습니다.

지원 범위

  1. 현재 공식 실행 패키지는 Windows 기준으로 안내합니다.
  2. 공식 독립 실행 파일은 아직 배포되지 않았습니다.
  3. 소스 실행에는 Python 3가 필요합니다.
GitHub 저장소의 README와
IDE/README.md를 참고하세요.

지원 환경이 확대되면 실행 절차를 이 페이지에 추가합니다.
